# Capturas que debes añadir manualmente

Guarda aquí tus capturas reales. No incluyas capturas simuladas.

Capturas mínimas recomendadas:

1. Repositorio de GitHub con ramas y Jenkinsfile.
2. Pull request creado y revisado.
3. Jenkins con el pipeline ejecutado.
4. Stage de tests automatizados en verde.
5. Logs de construcción de imagen Docker.
6. Análisis SonarQube.
7. Análisis Trivy.
8. Imagen publicada en DockerHub.
